# Bodhuno full-length Police mock previews

Two 200-question practice simulations are available as separate guest-access collections:

- `sets/telangana-police-si-full-mock-01-preview.json`
- `sets/telangana-police-constable-full-mock-01-preview.json`

Each mock contains 200 distinct English question stems, Telugu translations, four options in each language, a keyed answer and explanations in both languages. The Constable mock retains English practice. The SI mock excludes English-subject items and includes Telangana Movement / State Formation content.

## Exam format

| Feature | Mock setting |
|---|---:|
| Questions | 200 |
| Maximum marks | 200 |
| Duration | 180 minutes |
| Timer allocation | 54 seconds per question |
| Correct answer | +1 |
| Incorrect answer | −0.20 |
| Unanswered | 0 |

The marking rule and official test format are based on the TGPRB SI and PC 2026 Preliminary Written Test notifications. These are original Bodhuno practice mocks, not official TGPRB papers, official previous-year papers or predictions of the official question paper.

## Preview and review status

Both sets remain `preview`. The underlying collections are composed from the existing track-specific question banks and additional generated practice questions. The Constable source-bank duplicate is omitted from the full mock. New practice items and all Telugu wording still require independent subject-expert and Telugu-language review before publication. Do not promote either mock to `published` until that review is recorded in the set metadata.

## Validation checklist

Before promoting the mock sets:
1. Independently solve all 200 questions and verify each answer key and explanation.
2. Review syllabus distribution and topic weightings against the relevant notification annexure.
3. Review Telugu terminology, meaning and grammar with a qualified reviewer.
4. Run the question-bank validator and live Playwright full-mock flows.
5. Confirm the Cloudflare Pages deployment for the exact commit.
